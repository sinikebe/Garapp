Garapp sur cet appareil

Installer Garapp ajoute une icône pour l’ouvrir comme une application. Le garage reste propre à cet appareil et à ce navigateur.

Garapp est installé ou ouvert comme une application.

Depuis le navigateur

  • Android : ouvrir le menu du navigateur, puis choisir l’installation de l’application ou l’ajout à l’écran d’accueil.
  • iPhone et iPad : dans Safari, choisir Partager → Sur l’écran d’accueil, puis « Ouvrir comme app web » si proposé.
  • PC, Mac et Linux : dans Chrome ou Edge, choisir l’installation de la page comme application dans le menu du navigateur.

Accès hors connexion

Préparation de l’accès hors connexion…

Une première ouverture connectée et la confirmation de disponibilité sont nécessaires. Les mises à jour sont proposées sans rechargement forcé.

Une copie JSON permet de retrouver le garage après un changement d’appareil, de navigateur ou une suppression des données. L’installation et le mode hors connexion ne remplacent pas cette sauvegarde.

GARAGE ET DOCUMENTS

Sauvegardes

Conserver une copie

Un fichier JSON complet, avec les documents et les informations complémentaires. Chaque téléchargement porte un nom distinct et horodaté.

Le navigateur ne confirme pas la conservation du téléchargement : vérifier sa présence dans les fichiers.

Travailler avec un fichier lié

Choisir un fichier pour le mettre à jour sans multiplier les téléchargements. Des copies datées restent utiles pour revenir à une ancienne version.

La liaison directe à un fichier n’est pas disponible dans ce navigateur. Le téléchargement et l’import JSON restent accessibles.

L’écriture automatique s’arrête à la fermeture de la page ou en cas d’erreur. Elle doit être réactivée à la prochaine ouverture.

Synchroniser avec Google Drive

Facultatif · Versionné

Retrouver le garage sur plusieurs appareils avec le même compte Google. Chaque version est un fichier JSON complet, avec les documents et les informations complémentaires, dans un dossier privé de Mon Drive.

La connexion Drive attend sa configuration pour Garapp. Ce réglage est effectué une seule fois pour l’application ; chaque utilisateur peut ensuite se connecter avec son compte Google. Les sauvegardes JSON restent disponibles.

Configuration Google pour les essais en développement

Renseigner l’identifiant public d’un client OAuth de type Web. Le projet Google doit activer l’API Drive et autoriser cette origine : . Ce réglage est propre à cet appareil et à la version dev.

Aucun secret client, jeton ou mot de passe ne doit être saisi ici.

Seuls les dossiers privés créés par cette application et cette version sont proposés. Choisir un dossier ne remplace pas le garage ouvert.

Créer un nouveau dossier de sauvegarde

La création enverra le garage complet affiché ci-dessus, documents inclus, sur le compte Google connecté.

Vérification toutes les 15 secondes, au retour dans l’application et après une modification enregistrée. La fermeture de Garapp et l’expiration de la connexion Google interrompent les transferts ; une reconnexion explicite est nécessaire. Dev et main utilisent des dossiers distincts.

    Les modifications concurrentes sont conservées comme des versions séparées, à comparer avant tout choix. Chaque version complète utilise de l’espace Drive ; aucune suppression automatique n’est effectuée. Ces fichiers sont privés sur Drive, sans chiffrement supplémentaire par Garapp. Conserver aussi une copie JSON sur un autre support protège des suppressions ou erreurs de compte.

    Avec les fichiers seuls, transférer le dernier JSON puis l’importer sur l’autre appareil. Ces copies ne sont pas fusionnées automatiquement.
